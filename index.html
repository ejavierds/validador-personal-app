Términos de Uso

Bienvenido al Sistema de Validación de Personal del Municipio Jiménez.

1. Uso del Sistema: Este sistema es de uso exclusivo para la verificación de identidad del personal adscrito al Municipio Jiménez y sus dependencias de salud.

2. Veracidad: La información arrojada por este sistema es de carácter informativo e institucional, respaldada por la base de datos oficial de recursos humanos.

3. Restricciones: Queda estrictamente prohibido el uso de este sistema para fines comerciales, extracción masiva de datos o cualquier actividad ilícita.

×

Política de Privacidad

El Municipio Jiménez se compromete a proteger la privacidad del personal.

1. Datos Personales: Los datos mostrados (nombres, cédula, cargo, edad, etc.) son estrictamente los necesarios para la validación de la relación laboral o institucional.

2. Seguridad: El sistema no almacena las búsquedas ni la información de los usuarios que realizan las consultas. Toda la información es transmitida de forma segura.

3. Consentimiento: Al utilizar esta plataforma, usted acepta el manejo de datos exclusivamente para fines de verificación de identidad institucional.
